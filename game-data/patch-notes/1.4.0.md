# Generic — Patch 1.4.0

**Released:** 2026-07-28

## Changes

- Added the Sunken Archive region and its three side quests.
- Rebalanced the Warden enemy type: -15% health, +10% attack speed.
- Controller vibration can now be disabled independently of rumble intensity.
- Fixed several floating-object visual glitches in the Marsh biome.
- Improved matchmaking queue times for the Trials game mode.

## Known issues carried into this patch

See `known-issues/` for the current list, including KI-014 (Cathedral crash), which is not
fixed by this patch.
