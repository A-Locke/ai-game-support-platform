# KI-021 — Controller disconnects during Trials matchmaking

**Status:** Investigating
**Affects:** PC (Bluetooth controllers only)

## Description

A small number of players report their controller disconnecting specifically while a Trials
match is being found, reconnecting automatically once the match starts. No reports of this
happening during normal gameplay.

## Workaround

Using a wired connection instead of Bluetooth avoids the issue entirely.
