# KI-021 — Intermittent session timeout switching workspaces on mobile Safari

**Status:** Investigating
**Affects:** iOS Safari only

## Description

A small number of users report being logged out unexpectedly when switching between workspaces
on mobile Safari (iOS). Not reproduced yet on desktop Safari, Chrome, or other mobile browsers.

## Workaround

Reloading the page after switching workspaces avoids the issue in most reports.
