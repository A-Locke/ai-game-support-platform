# ExampleCo — Release 1.4.0

**Released:** 2026-07-28

## Changes

- Redesigned the main dashboard with customizable widgets.
- Added scheduled report delivery (daily/weekly email digest).
- Two-factor authentication can now use authenticator apps (TOTP), not just SMS -- see
  [[ExampleCo — Customer FAQ]] for setup steps.
- Fixed several layout glitches on narrow browser windows.
- Improved load times for workspaces with a large number of projects.

## Known issues carried into this release

See `known-issues/` for the current list, including
[[KI-014 — App crashes exporting a report with more than 10,000 rows]] (large export crash),
which is not fixed by this release.
